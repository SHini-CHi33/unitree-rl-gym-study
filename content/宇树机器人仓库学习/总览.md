# 宇树人形机器人行走仓库学习计划：Day 1–Day 18

我建议整个学习计划安排为 Day 1–Day 18。前 7 天理解环境和控制系统，接下来进入 PPO 算法和实际训练，再完成实验与 Sim2Sim 部署。

## 第一阶段：理解机器人环境与控制系统

**Day 1–7**

| 天数    | 学习主题                                                | 核心目标                    |
| ----- | --------------------------------------------------- | ----------------------- |
| Day 1 | 训练入口、配置加载、环境创建、OnPolicyRunner、learn()               | 理解训练程序如何启动              |
| Day 2 | G1 机器人关节、URDF、初始姿态、PD 控制参数                          | 理解机器人模型和配置              |
| Day 3 | Observation 的构成与 47 维输入、50 维 Privileged Observation | 理解 Actor 和 Critic 看到了什么 |
| Day 4 | 12 维 Action、action_scale、目标关节角映射                    | 理解策略输出代表什么              |
| Day 5 | PD Controller、Torque、Decimation、5ms 与 20ms 时间尺度     | 理解高层策略与底层控制如何协作         |
| Day 6 | Reward 函数、Reward Scale、奖励汇总                         | 理解机器人如何评价自己的运动表现        |
| Day 7 | Reset、Termination、Command 采样、Domain Randomization   | 理解 Episode 生命周期和环境随机化   |

## 第五阶段：项目整理与简历项目化

**Day 17–19 · 最终验收**

| 天数     | 学习主题            | 最终产出             |
| ------ | --------------- | ---------------- |
| Day 17 | 整体架构复盘          | 一张完整 G1 RL 系统架构图 |
| Day 18 | 关键代码讲解与实验复盘     | 能够解释核心函数和实验结果    |
| Day 19 | 项目文档与 GitHub 整理 | 一个有代码、有实验、有解释的项目 |

最终需要准备：

1. 系统架构图：从训练入口到机器人运动执行。
2. Observation / Action / Reward 设计说明。
3. PPO 训练过程说明。
4. 至少一个自己完成的单因素实验。
5. 训练曲线和实验对比结果。
6. Play 或 Sim2Sim 运行说明。
7. 项目 README 和技术难点总结。

## 最终达到什么程度才算学完？

我设置五个验收标准：

1. **能解释：** 不看教程，能够解释 G1 从 Observation 到 Action、PD、Reward、PPO 更新的完整流程。
2. **能运行：** 能独立启动训练、监控训练过程、加载 Checkpoint 并运行策略。
3. **能修改：** 能修改 Reward、Command、Domain Randomization 等关键配置，并知道影响范围。
4. **能验证：** 能设计单因素实验，用训练数据和机器人表现验证自己的假设。
5. **能部署和表达：** 能解释 Sim2Sim 接口，并把整个项目整理成可以在 GitHub 和简历中展示的技术项目。

我的建议是：**Day 19 作为第一轮学习的结束点。** 这不是说 19 天就能成为人形机器人强化学习专家，而是希望你完成从“能够运行官方工程”到“能够独立理解、修改和验证一个 G1 强化学习系统”的转变。
